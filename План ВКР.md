# ВКР

## Тема: Исследование сред исполнения серверного JavaScript кода (node, deno, bun)

## План ВКР (Содержание)

### Анализ проблемы и актуальность

- Почему стоит использовать серверный js при разработке веб приложения (в сравнении с другими языками программирования). Для каких целей лучше всего подходит js. (Единый язык для фронтенда и бекенда, ...)
- Проблемы существующей nodejs (Плюсы и минусы, и почему вообще создаются альтернативы)
- Актуальность новых сред исполнения, их преимущества и недостатки
- (Тренды перехода с ноды: много ли проектов переводят на другую среду исполнения, начинают новые проекты сразу не на ноде, почему они приняли такое решение)

### Описание эксперимента по производительности node, deno, bun

(Можно ещё тестировать скорость сборки, скорость запуска тестов, скорость чтения и записи файлов, но хочется сосредоточиться именно на веб, а именно http запросах и чтения с базы)

- Эксперимент будет производиться на виртуальных машинах средней мощности в яндекс облаке
- Настроика виртуальной машины через ansible
- Тест производительности при синхронных вычислениях (Например, маппинг из одних данных в другие, парсинг)
- Тест производительности при http запросах сущностей из postgres
- Тест производительности при отправке через http картинки с сервера
- Тест производительности по websocket

### Проведение эксперимента и его результаты

- Измерить нагрузки процессора, памяти, скорости работы кода
- Графики и выводы по ним
- Заключение не только про производительность, но и по другим плюсам новых сред выполнения
